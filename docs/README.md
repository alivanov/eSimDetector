## Ключевые принципы решения

1. **Приоритет точности над полнотой.** Ложный положительный или отрицательный ответ дороже честного «требуется уточнение». Все пороги настроены так, чтобы при недостатке данных уходить в сценарий уточнения.
2. **Объяснимость.** Каждый ответ сервиса сопровождается перечнем сигналов и правил, которые к нему привели. Решение не является «чёрным ящиком».
3. **Детерминированность.** Основной контур определения не использует внешние сервисы и генеративные модели: одинаковый вход всегда даёт одинаковый выход, что делает решение полностью покрываемым модульными тестами.
4. **Готовность к интеграции с первого запуска.** Демонстрационный сценарий поднимается одной командой без правки исходного кода.
5. **Проверяемость данных.** Каждое утверждение о поддержке eSIM имеет известное происхождение и уровень достоверности. Непроверенные данные не участвуют в ответах пользователю.
6. **Только подтверждаемое.** По правилам оценки учитываются лишь характеристики, подтверждаемые демонстрацией, контрольными сценариями, документацией или исходным кодом. Поэтому каждое заявленное свойство решения имеет предъявляемое доказательство.
